# SceneForge 运维与数据恢复

SceneForge 默认只监听 `127.0.0.1`。开放到局域网时必须设置 `SCENEFORGE_WEB_TOKEN`，并由可信反向代理提供 HTTPS。

## 启动诊断

升级依赖、迁移电脑或排查启动失败时先执行：

```powershell
uv run sceneforge-doctor --workspace .
```

诊断会检查 Python、FFmpeg、前端构建、状态目录与媒体目录写权限、SQLite 完整性和模型配置。模型未配置只会警告，不会阻止进入设置页。

服务启动后可请求 `GET /api/health`。接口只返回数据库与 FFmpeg 状态，不返回密钥、供应商配置或本地路径。

## 数据库备份

SQLite 数据库位于 `.sceneforge/sceneforge.db`。使用 SQLite 后端时，每次服务启动前会执行完整性检查，并将在线备份写入 `.sceneforge/backups/`，默认保留最近 7 份。备份会合并 WAL 中已提交的数据，不要用文件复制替代该流程。

手动检查和备份：

```powershell
uv run sceneforge-db check --workspace .
uv run sceneforge-db backup --workspace . --keep 7
uv run sceneforge-db list --workspace .
```

## 恢复数据库

先停止 SceneForge，再执行恢复。恢复命令会先备份当前数据库，校验目标备份，并清理旧的 WAL/SHM 文件：

```powershell
uv run sceneforge-db restore --workspace . --source .sceneforge/backups/sceneforge-时间戳.db --force
```

恢复完成后先运行 `sceneforge-db check`，再启动服务。生成媒体默认在 `.working_dir/`，数据库备份不包含媒体；迁移电脑时需要同时备份 `.working_dir/` 和自定义素材目录。

## 请求与上传限制

默认普通 API 正文上限为 4 MB，音频上传请求为 48 MB，视频上传请求为 384 MB；解码后的音频和视频分别限制为 32 MB、256 MB。可通过以下环境变量调整：

- `SCENEFORGE_MAX_REQUEST_BYTES`
- `SCENEFORGE_MAX_AUDIO_UPLOAD_BYTES`
- `SCENEFORGE_MAX_VIDEO_UPLOAD_BYTES`
- `SCENEFORGE_MAX_AUDIO_BYTES`
- `SCENEFORGE_MAX_VIDEO_BYTES`

提高限制会增加服务进程的峰值内存，个人本地使用不建议无上限放大。
