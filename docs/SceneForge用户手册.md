## 1. SceneForge 能做什么

| 你有 | 它产出 |
|---|---|
| **一句创意**（如"一只猫和一只狗成了好朋友"） | 自动写故事、设计角色、分镜、生成多场景成片 |
| **一段剧本**（自己写好的分场景脚本） | 按你的剧本直接出片，不改写原文 |
| **一整本小说** | 智能压缩→拆事件→场景化→逐集视频 |
| **你自己/宠物的照片** | 把真实形象作为"客串角色"贯穿整片 |
| **一段已有的视频** | 自动加字幕、配音、背景音乐、AI 合规角标 |

成片默认包含：AI 生成的画面 + 中/英配音 + 逐句字幕 + 背景音乐 + 音效 + 响度统一 + "AI 生成"合规标识，**可直接发布**。

## 2. 快速开始（3 步）

### 第 0 步：环境准备（仅第一次）

需要已安装 **Python 3.12** 和 **uv**（依赖管理工具）。在 `SceneForge` 目录打开终端执行一次：

```bash
uv sync
```

这会创建虚拟环境并装好所有依赖。装完后目录里会有 `.venv` 文件夹。

### 第 1 步：启动

双击 **`start.bat`**。会弹出一个黑色命令窗口并自动打开浏览器。

> ⚠️ **保持那个黑窗口开着** —— 它就是服务本体，**关掉窗口 = 停止服务**。

### 第 2 步：打开工作台

浏览器会自动打开 **http://127.0.0.1:8770/**。如果没自动打开，手动在浏览器输入这个地址即可。

看到左侧带"SceneForge"的界面就说明启动成功了。

## 3. 首次配置模型密钥（必做）

SceneForge 自己不含 AI 模型，需要你填入模型服务商的 **API Key** 才能生成。

1. 点左下角 **⚙️ 设置** → **🔑 模型**。
2. 分别配置四类模型（按你的服务商填）：
   - **对话模型（LLM）**：用于写剧本、分镜、选图评审 —— **必须是多模态模型**（能看图）。
   - **图像模型**：生成画面（如豆包 Seedream、nano-banana 等）。
   - **视频模型**：图生视频（如豆包 Seedance、Veo 等）。
   - **Embedding / Reranker**：仅"小说转视频"用到，其它场景可不填。
3. 每类填 `API Key`、`base_url`（网关地址）、选择具体 `model`（支持"厂商→型号"级联下拉，也可自定义）。
4. 点保存。密钥保存后会脱敏显示（只留末 4 位），不会明文回显。

> 💡 服务在没配 key 时也能启动，只是一点生成就会报错。配好 key 再生成即可。

## 5. 核心流程：从创意/剧本到成片

### 5.1 新建创作

进入 **🎬 创作**，点"新建创作"。有两种模式：

- **主题生成**：填一句创意，AI 帮你写剧本。适合"我只有想法"。
- **导入剧本**：粘贴你写好的剧本全文，系统按"场景一 / 第1场 / INT. / EXT."自动分场，**不改写你的原文**。适合"我有现成脚本"。

**本片设置**（只影响这一条片子，不动全局）：
- 语言（中文 / 英文 / 跟随剧本）
- 画面比例（横屏 16:9 / 竖屏 9:16 / 方形 1:1）
- 质量档位：
  - **省钱**：每个关键帧生成 1 张，每镜生成 1 个视频候选，速度最快。
  - **均衡（推荐）**：每个关键帧生成 2 张并自动选优，每镜生成 1 个视频候选。
  - **高质量**：每个关键帧生成 3 张并自动选优，每镜生成 2 个视频候选，等待更久、费用更高。
- 领域·风格 Skill（见第 9 节）
- 是否烧字幕、是否配音、配音音色（可点 ▶ **试听**）
- 背景音乐选择
- **出场角色**：从角色库勾选要锁定形象的角色（见第 6 节）
- 模板：可把常用的风格/要求存成模板，下次一键套用

填好点提交，进入生成。

### 5.2 逐阶段审核推进

SceneForge 不是"一键黑箱出片"，而是**分阶段、可审核**的。流程步骤条：

```
剧本  →  分镜脚本  →  分镜视频  →  终审/发布  →  完成
```

- 每个阶段生成后会**暂停等你审阅**。满意点 **通过**，进入下一阶段；不满意可：
  - **修改**：用一句话说明意见，让 AI 重做本阶段（如"节奏再快些""台词更口语"）。
  - **退回**：回到上一阶段（剧本或分镜），下游内容作废重来。
- 点已完成的阶段可查看内容：剧本全文、分镜脚本（可手动编辑）、逐镜视频、成片播放。

### 5.3 分镜脚本的精修

在"分镜脚本"阶段，可进入编辑器逐镜调整：
- 增 / 删 / 插入镜头
- 改画面描述、台词/音频、画面叠加文字及其位置（顶/中/底）
- 让 AI **重写单个镜头**（可给指令或留空让 AI 优化）

### 5.4 逐镜头重生成（出片后）

进入"分镜视频"看板，每个镜头一张卡片，实时显示生成进度和**质量徽章**（人物一致性/画质/贴合度/连贯性）。对不满意的镜头：
- **改提示词重生成**：编辑该镜的画面/台词后重生成。
- **直接重生成**：先选择人物、动作、连续性、构图或技术质量等返工原因，再选择人物、构图、动作、声音等锁定约束，在不改内容的情况下换一次结果。
- **批量审核**：点看板上方“批量审核”并勾选镜头，可批量接受当前视频、恢复各镜头的上一可用版本，或统一设置返工原因和锁定约束后提交返工。恢复上一版会跳过没有更早可用版本的镜头，并在完成后统一重建成片。
- **返工预览**：点“预览影响与费用”后，会显示选中数、连续性依赖合并后的实际影响数、最小执行根数和预计新增费用；同时对比整片全部重做，显示预计少生成镜头数、节省比例、时间和费用。
- **版本对比与批注**：展开“视频历史版本”，可把历史版本与当前版并排播放、重新选择历史版本，也可对任意版本添加批注。批注可填写视频内的秒数，始终绑定当时选中的具体版本。

看板顶部同时显示首次通过率、质量通过率、返工次数、平均生成时间和镜头费用。选择某个镜头后，可查看本镜使用的供应商/模型、请求次数、重试次数、生成耗时和费用依据。

> 只重算这一镜及其依赖镜，不会重跑整片，省时省钱。
>
> "实付已回传"只在供应商明确返回账单字段时出现；其他费用均标为"预计"或"待供应商回传"，不会把估算冒充真实账单。
>
> 返工费用预览的下限按受影响镜头和候选数计算，上限额外包含配置的重试次数。视频模型 Profile 未配置单次估价时，界面会显示“费用待模型单价配置”。人物、构图、动作和声音锁定属于模型生成约束，不是像素级冻结保证。
>
> 成功完成的批量返工会把预计节省写入项目生产记录，并在看板顶部累计展示。这里的时间节省来自本项目历史单镜平均生成时间，费用节省沿用当前 Profile、候选数和重试配置，均属于可解释估算而非供应商账单。

### 5.5 下载与发布

成片阶段可：
- **调整剪辑方案**：展开“剪辑方案”，调整镜头顺序、每镜入点/出点，以及项目级硬切、交叉溶解或淡入淡出。
- **保存或重新合成**：保存仅记录方案；重新合成会作为后台任务执行，完成后自动刷新终审播放器。
- **恢复原始成片**：首次重新合成会保留不可变原始源；后续可一键恢复，重新合成和恢复前都会归档当前版本。
- **校正字幕文件**：展开“字幕时间线”，可直接修改每句字幕文本、开始时间和结束时间；保存前会检查时间边界和排列顺序。
- **恢复或下载字幕**：可恢复到当前成片对应的生成字幕，或下载标准 SRT 文件交给发布平台和剪辑软件。
- **下载成片**（mp4）
- **获取分享链接**（若配置了托管/飞书，会回传可分享链接；否则返回本地路径）
- **成本估算**（估算值，非真实账单）
- **清理中间文件**（回收逐镜片段/中间图，保留成片/海报/字幕/剧本，释放磁盘）

> 💡 服务中途重启后，未完成的会话会显示"中断"，点**继续生成**可断点续跑，不用从头再来。
>
> 轻量剪辑基于已经完成声音、字幕和 BGM 合成的成片切段，因此不会触发视频模型重生成。它适合镜头级排序、裁剪和基础转场；多轨音频、关键帧动画、精细调色仍应交给专业剪辑软件。
>
> “字幕时间线”编辑的是项目级 SRT 字幕文件，不会自动重烧已经导出的 MP4；需要画面内字幕同步变化时，应在后续烧录流程或专业剪辑软件中使用下载的 SRT。

## 6. 角色库：锁定人物形象

AI 视频最头疼的是"同一个人每个镜头长得不一样"。用固定角色解决：

1. 进 **🎭 角色库** → 新建角色：填英文 ID（唯一）、显示名、外貌描述、别名。
2. 生成 **正面 / 侧面 / 背面** 立绘（侧/背以正面为参考，锁定脸型发型服装）。
3. 不满意可反复重新生成；每次生成前会自动**存历史版本**，可随时**回滚**到之前的版本。
4. 回到 **🎬 创作** 新建时，在"出场角色"里勾选该角色 → 这条片子每个镜头都复用它的形象，且剧本会沿用角色名。

> 上传你自己/宠物的照片作为角色形象，就是 **AutoCameo（本人客串）** 的玩法。

## 7. 音频：配音 / 背景音乐 / 音效

成片默认不是"哑片"。在**设置 → 🔊 音频**里配置（也可在创作时按片选音色）：

- **配音（TTS）**：支持两家服务
  - OpenAI 兼容音色（多语种）
  - MiniMax 中文音色（情感更强，如"精英青年/霸道青年/御姐/少女"等）
  - 可**在线试听**再决定用哪个音色；配音会按台词时长自动对齐字幕。
- **背景音乐（BGM）**：上传你自己的音乐到曲库，选一首作为默认，可调音量；开启“对白时自动降低音乐”后，可选择轻柔、标准或明显三档压低强度。
- **音效（SFX）**：把音效文件按"关键词"命名上传到音效库；分镜里出现对应关键词时自动匹配落位。没有匹配就静默跳过。
- **响度归一化**：自动统一全片音量（EBU R128），不用手动调。

> 配音/音乐/音效都是**可选**的：没配就跳过，不会报错。

## 8. 画面：字幕 / 转场 / 开场钩子 / 封面 / 合规标识

在**设置 → 🎬 画面 / 📝 字幕与文案 / 🛡️ 合规与质量**里控制：

- **字幕**：开/关烧录、颜色、位置、描边、字号；中文自动用合适字体。成片生成后还可在终审页校正项目级字幕时间线并下载 SRT。
- **转场**：硬切 / 交叉溶解 / 淡入淡出。
- **开场钩子**：视频前 3 秒的爆款式浮层文字，可让 AI 自动生成（多候选选最优）或手动填。
- **封面海报**：自动从成片抓一帧导出缩略图。
- **AIGC 合规标识**（**默认开启**）：全片常驻半透明"AI 生成"角标，并写入视频元数据，符合国内生成式 AI 内容标识要求。**建议保持开启。**
- **质量自评**：AI 自动逐镜检查人物一致性/画质/贴合度/连贯性，不达标自动重生成（阈值可调，越严越稳但越慢越费）。

## 9. 风格与领域（垂类化）

同一套引擎可产出不同垂类风格。在创作时的"领域·风格 Skill"下拉里选：

- **内置领域**：短剧/爽文、影视解说、知识科普、通用。
- **我的 Skill**：你自己上传的风格文件（见下）。

**Skill 市场（🎨）**：
- **上传风格**：风格是一个 `.md` 文本文件（含"剧本/分镜/视频/钩子"分节），上传后即可在创作里选用。纯文本、无代码，安全。
- **示例模板**：内置"赛博朋克悬疑短剧 / 国风仙侠 / 暖心治愈"，点导入即可用。
- **fork 内置**：把内置风格复制成可编辑的副本，改成你要的调性。

## 10. 自动后期：给外部视频加字幕配音

**🪄 自动后期** 页处理的是**你导入的现成视频**（不是本系统生成的）：

1. 上传一段视频。
2. 点"转写台词"（自动语音识别，出带时间戳的文字）。
3. 勾选要加的东西：字幕 / 配音（替换或叠加原声）/ 背景音乐 / AIGC 角标。
4. 生成 → 下载。

> ⚠️ 它**不做**剪辑、裁剪、拼接、变速、转场、调色、口型同步。"换旁白"是换音轨，不会改嘴型。要精剪请用剪映等工具。

## 11. 设置页详解

左侧子菜单 6 类：

| 分类 | 内容 |
|---|---|
| 🔑 **模型** | LLM / 图像 / 视频 / Embedding / Reranker 的密钥与型号 |
| 🔊 **音频** | 配音音色（含试听）、背景音乐库、音效库 |
| 🎬 **画面** | 画面比例、转场、开场钩子、封面海报、画面内文字策略 |
| 📝 **字幕与文案** | 字幕开关与样式 |
| 🛡️ **合规与质量** | AIGC 标识、内容审核敏感词、生成预算上限、质量自评阈值 |
| 🧩 **扩展** | Skill 市场地址等 |

> 数字类设置项旁边有 **"?" 悬停说明**，不知道怎么填时把鼠标放上去看提示。多数高级开关**默认关闭**，不动它们就是最稳的默认行为。

**生成预算**（合规与质量里）：可设"最多几个场景 / 最多几个镜头"，超了会在进入最贵的视频生成前拦下，防止意外烧钱。

### 飞书消息入口（进阶）
系统支持通过飞书消息驱动"提交—审核—发布"工作流：在飞书里发主题，机器人推审核卡，回复"通过/修改/重生成第 N 镜/发布"即可驱动。需要配置飞书 `APP_ID/SECRET` 和公网地址，属进阶用法。

> 🔐 **安全提示**：访问令牌 = 你的模型密钥和钱包。只发给信任的人；不用时把 `start.bat` 里的令牌清空或换掉即可作废。

## 13. 名词解释

| 术语 | 含义 |
|---|---|
| **会话 / 创作** | 一条视频的完整生产任务，产物存在独立目录，可中断续跑 |
| **分镜（storyboard）** | 把剧本拆成一个个镜头，每镜有画面/台词/时长 |
| **镜头（shot）** | 分镜里的最小单元，对应一小段视频 |
| **立绘 / 参考图** | 角色的标准形象图，用于保证跨镜头一致 |
| **机位** | 拍摄视角；同机位画面互相继承以保持空间一致 |
| **钩子（hook）** | 开场 3 秒抓眼球的浮层文字 |
| **领域 / Skill** | 题材风格包（短剧/解说/科普…），影响 AI 的写作和分镜风格 |
| **AIGC 标识** | "AI 生成"合规角标，符合国内内容标识要求 |
| **管理令牌（token）** | 后台访问口令，可读取配置并触发生成，只能交给可信管理员 |
| **TTS** | 文字转语音（配音） |
| **一致性自评（Critic）** | AI 自动检查画面是否合格并触发重生成 |
