风格 Skill 目录
================

把你下载/编写的风格 Skill（.md 文件）放进这个目录，或直接在网页「创作 → 🎨 Skill 市场」里上传。
重启服务器或重新打开 Skill 市场后即可在「领域 / 风格 Skill」下拉里选用。

只有 *.md 文件会被加载（本说明是 .txt，不会被当成 Skill）。

文件格式（YAML 头 + 分节正文）
------------------------------

    ---
    name: 赛博朋克悬疑短剧        # 显示名称
    key: cyberpunk_drama         # 唯一标识（可省略，省略时用文件名）
    author: 你的名字              # 可选
    ---

    ## 剧本
    注入「编剧」环节的题材化指导：高概念反乌托邦设定，台词冷硬，每场留悬念。

    ## 分镜
    注入「分镜」环节：大量低角度、霓虹光比、雨夜街景，反转给反应镜头。

    ## 视频
    追加到每个画面/视频生成提示词的视觉风格：
    cyberpunk, neon-lit, rain, cinematic, teal-orange

    ## 钩子
    注入「开场钩子」：用一句反乌托邦冷启动。

说明
----
- 四个小节都是可选的，至少要有其中一节才算有效。
- 小节标题支持中英文：剧本/Script、分镜/Storyboard、视频/Video、钩子/Hook。
- Skill 只是纯文本提示词，不包含任何可执行代码，导入安全。
- 不选任何 Skill = 行为与默认完全一致。
