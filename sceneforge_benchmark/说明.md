# SceneForge 质量基准

该目录包含 35 个固定故事、104 个场景和 437 个镜头，覆盖三类一致性问题：

- Type A：同一角色跨不同环境的一致性。
- Type B：同一空间跨不同机位的一致性。
- Type C：多角色同框与交互的一致性。

先执行离线数据门禁，不会调用模型，也不会产生费用：

```bash
uv run python scripts/run_benchmark.py
```

真实模型测试结果使用 JSONL，每行代表一个案例。必填字段为 `case`、`provider`、`model`、`status`；可选质量字段 `identity`、`temporal`、`composition`、`prompt_adherence` 的取值范围为 0 到 1，还可记录 `seconds`、`retries` 和 `cost`。

```json
{"case":"chef_international_kitchens","provider":"example","model":"video-v1","status":"succeeded","identity":0.86,"temporal":0.78,"composition":0.82,"prompt_adherence":0.9,"seconds":94,"retries":1,"cost":1.2}
```

汇总真实结果：

```bash
uv run python scripts/run_benchmark.py --results results.jsonl --output report.json
```

CI 只执行离线门禁。真实模型生成必须人工触发并明确选择供应商，避免自动消耗额度。
